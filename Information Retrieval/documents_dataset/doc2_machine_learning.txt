Machine learning is a branch of artificial intelligence that enables systems to learn and improve from experience without being explicitly programmed. Machine learning focuses on the development of computer programs that can access data and use it to learn for themselves. The process of machine learning begins with observations or data, such as examples, direct experience, or instruction, to look for patterns in data and make better decisions. Machine learning algorithms are often categorized as supervised and unsupervised. Supervised machine learning algorithms can apply what has been learned in the past to new data using labeled examples. Unsupervised machine learning algorithms are used when the information used to train is neither classified nor labeled. Reinforcement machine learning algorithms interact with their environment by producing actions and discover errors or rewards. Machine learning enables analysis of massive quantities of data. Machine learning is being used in email filtering, fraud detection, and recommendation engines. Machine learning has evolved from pattern recognition and the theory that computers can learn without being programmed. Machine learning is similar to computational statistics. The adoption of machine learning across industries is driven by the same factors that make data mining and Bayesian analysis more popular.
