Deep learning is a subset of machine learning that uses layered neural networks to simulate human decision-making. Deep learning is behind many of the recent breakthroughs in artificial intelligence. Deep learning is what powers many of the most advanced technologies from image recognition, natural language processing, and speech recognition. Deep learning neural networks are designed to mimic how the human brain works. Deep learning requires both artificial neural networks with many layers. The adjective deep refers to the number of hidden layers in the neural network. Traditional neural networks only contain two or three hidden layers, while deep networks can have as many as a hundred. Deep learning models are trained by using large sets of labeled data and neural network architectures that learn features directly from the data without requiring manual feature extraction. Deep learning drives many practical applications: from self-driving cars to medical diagnostic tools. Deep learning is particularly useful in image classification, object detection, and segmentation tasks. Deep learning reduces much of the feature extraction that previously had to be done manually. Deep learning models are trained with the backpropagation algorithm to improve accuracy over time.
